DARKSLAYERS - ROSTER CONNECTED

CE FACE:
- Leaga contul Supabase de roster prin user_id.
- MAIN Character apare automat in roster.
- Un cont nou primeste automat rank MEMBER.
- Utilizatorul NU isi poate da Veteran / Core Raider / Officer / Guild Master.
- Daca staff-ul promoveaza membrul, sincronizarea profilului pastreaza rank-ul dat de staff.
- Schimbarea numelui/clasei/jocului/levelului la MAIN actualizeaza rosterul.
- Daca utilizatorul schimba MAIN-ul, rosterul se muta pe noul MAIN.
- Daca nu mai exista MAIN, intrarea conectata este scoasa din roster.
- In profil, utilizatorul normal are titlul Membru DARKSLAYERS.

INSTALARE:
1. Supabase -> SQL Editor -> copiaza tot din SUPABASE-ROSTER-CONNECTION.sql -> Run.
2. Pe GitHub inlocuieste index.html, script.js si style.css.
3. Commit changes.
4. Pe darkslayers.ro: Ctrl+F5.
5. Login -> CONT -> PROFILUL MEU -> seteaza un caracter MAIN -> SALVEAZA.
6. Verifica ROSTER.

CNAME este inclus doar pentru siguranta; nu trebuie schimbat daca domeniul merge deja.
