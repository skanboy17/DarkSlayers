DARKSLAYERS - AVATAR MODERATION

1. Run SUPABASE-ROSTER-CONNECTION.sql if you have not already run it.
2. Run SUPABASE-AVATAR-MODERATION.sql.
3. Replace index.html, script.js and style.css on GitHub.
4. Ctrl+F5 on the live site.

RULE:
- Members upload a pending avatar.
- It is NOT made public automatically.
- Admin/Officer approves or rejects it.
- Only avatar_url is public/approved.
